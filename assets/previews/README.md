# Preview thumbnails

AI-generated with FLUX.2 klein 4B (Apache-2.0) on this machine: one synthetic adult per look (Man, Woman, Non-binary, Alien, Monster), always fully clothed, one attribute changed per image. They show no real person, brand or logo. Each file, its prompt scaffold, framing and seed are listed in `manifest.json` and can be rebuilt with `scripts/thumbs/`.

Set of 183 shipped thumbnails (217 generated; 34 were left out because a photo did not visibly show the option, see scripts/thumbs/exclude.json). Anything missing falls back to drawn art in the app.
